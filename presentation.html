🔑 Key Design Decisions

• DB subnets have no default route — zero internet exposure
• Single NAT GW in AZ-1 (cost-optimised for dev)
• ALB spans all 3 public subnets for HA
• Each app EC2 in its own AZ for fault isolation
• DNS hostnames + DNS support enabled on VPC

WAF Configuration

WAFv2 Regional Web ACL attached to ALB · CloudWatch logging enabled

📋 Managed Rules (Priority Order)

#Rule SetProtects Against
1AWSManagedRulesCommonRuleSetOWASP Top 10
2AWSManagedRulesKnownBadInputsRuleSetLog4Shell, SSRF, bad payloads
3AWSManagedRulesSQLiRuleSetSQL injection
4RateLimitRule (custom)DDoS / brute force
Default action: ALLOW (rules block matching traffic)
Rate limit: 2,000 requests / 5 min per IP

📊 Observability

• CloudWatch Log Group: aws-waf-logs-{prefix}
• Retention: 30 days
• Sampled requests enabled on all rules
• CloudWatch metrics per rule for alerting

🔗 Association

• aws_wafv2_web_acl_association binds ACL to ALB ARN
• Scope: REGIONAL (not CloudFront)
• All rules set to override_action: none
💡 To add IP allowlisting (corporate CIDR), add a priority 0 rule with action: allow before the managed sets.

Security Hardening

Defence-in-depth across compute, network, data, and access layers

🖥️ Compute (EC2)

IMDSv2 enforced (http_tokens = required)
EBS root volumes encrypted (gp3)
SSM Session Manager — no SSH port open
IAM instance profile with least-privilege SSM policy
No public IP assigned to app instances

🗄️ Database (Aurora)

Storage encryption enabled at cluster level
publicly_accessible = false on all instances
DB subnets have no internet route table entry
Automated backups 7-day retention
Final snapshot on destroy
PostgreSQL logs exported to CloudWatch

🌐 Network

SG-to-SG references — no CIDR between tiers
DB tier isolated route table (no default route)
HTTPS redirect when ACM cert provided
TLS 1.3 policy on HTTPS listener
WAF SQLi + OWASP rules before ALB

Deployment Steps

From zero to provisioned infrastructure in 4 commands

1

Configure variables

Copy terraform.tfvars.example → terraform.tfvars and set client_name, ec2_ami, db_master_password

2

terraform init

Downloads AWS provider ~> 5.40, initialises all 6 child modules

3

terraform plan -out=tfplan

Review ~45 resources across VPC, SGs, ALB, WAF, EC2, RDS. Verify naming + tags before apply

4

terraform apply tfplan

~8–12 min. Aurora cluster takes the longest. Outputs print on completion

5

Destroy (cleanup)

terraform destroy — final RDS snapshot is taken automatically before deletion
